# Wine Classification

## About the Project

This project is about using machine learning to classify wine samples based on the features available in the dataset.

I worked on preparing the data, handling class imbalance using SMOTE, and training different classification models. I also compared the models to understand how their performance differs.

## What I Did

- Loaded and explored the dataset.
- Prepared the data for classification.
- Used SMOTE to handle class imbalance.
- Trained Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM) models.
- Evaluated the models using accuracy scores.
- Compared the models' performance.
- Practiced saving and loading a trained model using Pickle.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Imbalanced-learn (SMOTE)
- Pickle
- Google Colab

## How to Run

1. Clone or download this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Upload the dataset and update its file path if needed.
4. Install any missing libraries.
5. Run the notebook cells in order.
6. Check the model evaluation results.

## What I Learned

This project helped me practice classification algorithms, data preprocessing, handling imbalanced data, comparing model performance, and saving a trained machine learning model.
